# Top-down Stealth Sprite Pack

Original generated placeholder assets for a 2D top-down stealth/heist game.

## Structure
The ZIP preserves the requested paths and file names.

## Animation strips
- `players/p1_walk.png`: 8 frames, each 32x32, horizontal strip = 256x32.
- `players/p2_walk.png`: 8 frames, each 32x32, horizontal strip = 256x32.
- `guards/guard_walk.png`: 8 frames, each 32x32, horizontal strip = 256x32.
- Idle files are single 32x32 frames.

## Notes
- Transparent PNGs are used where appropriate.
- `laser_beam.png` is vertical and stretchable.
- `alarm_overlay.png` is a transparent red vignette overlay.
- No `.ttf` font file is included. Use a free pixel font such as "Press Start 2P", "Pixelify Sans", or another OFL-licensed font separately.
- These assets are generated from scratch for placeholder/prototype use.
